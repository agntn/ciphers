Same tableau as [Quagmire I](/ciphers/quagmire-1), the keyword just moved downstairs. Plain A to Z sits on top. `SPRINGFEVABCD…` slides underneath, and the indicator still runs down the column under plain A.

```ts
const quagmire = create("quagmire-2");
const keys = { key: "SPRINGFEVER", indicator: "FLOWER" };
quagmire.encode("In the quag two", keys).text; // "Ji cic osly kil"
quagmire.decode("JICICOSLYKIL", keys).text; // "INTHEQUAGTWO"
```

Same keys as the Quagmire I example, different ciphertext. That's the [ACA's Quagmire II](https://www.cryptogram.org/downloads/aca.info/ciphers/QuagmireII.pdf), which starts `JICIC OSLYK` too.

## Is it any easier?

A little. With the plain side straight, every row is the same keyed alphabet at another shift. That's a Vigenère with a scrambled alphabet, nothing worse. Rebuild the cipher alphabet from the columns and look at it. See where it starts running in alphabetical order? Everything before that is usually the keyword.

Text, case, errors and [`period`](/guide/analysis) work as for [Quagmire I](/ciphers/quagmire-1#the-rest-of-the-text).
