::cipher-facts{name="quagmire-3"}
::

Quagmire III keys both alphabets with the same word. `AUTOMOBILE` gives `AUTOMBILECDF…`, on top and underneath. The indicator runs down the column under plain A, as in [Quagmire I](/ciphers/quagmire-1).

```ts
const quagmire = create("quagmire-3");
const keys = { key: "AUTOMOBILE", indicator: "HIGHWAY" };
quagmire.encode("the same keyed alphabet", keys).text; // "krs lwmi tjdvi abmrgqmt"
quagmire.decode("KRSLWMITJDVIABMRGQMTM", keys).text; // "THESAMEKEYEDALPHABETI"
```

From the [ACA's example](https://www.cryptogram.org/downloads/aca.info/ciphers/QuagmireIII.pdf), period 7. See the second H in HIGHWAY? Rows one and four are the same row. Nobody minds.

## Why does it feel like Vigenère?

Because it is one, wearing a name tag. Swap every letter for its place in the keyed alphabet and Quagmire III turns into a plain Vigenère. Solve that, and the keyword falls out of the alphabet you rebuilt along the way.

Text, case, errors and [`period`](/guide/analysis) work as for [Quagmire I](/ciphers/quagmire-1#the-rest-of-the-text).
