Trifid turns letters into coordinates, then mixes those coordinates. It uses a cube instead of [Bifid's square](/ciphers/bifid). That extra dimension gives J its own cell.

```ts
const trifid = create("trifid");

trifid.encode("aide-toi, le ciel t'aidera", {
  key: "FELIX MARIE DELASTELLE",
  period: 5,
}).text; // "FMJFVOISSUFTFPUFEQQC"

trifid.decode("FMJFVOISSUFTFPUFEQQC", {
  key: "FELIX MARIE DELASTELLE",
}).text; // "AIDETOILECIELTAIDERA"
```

## The cube

Félix Delastelle described Trifid in his 1902 *Traité élémentaire de cryptographie*. It's a sibling of his Bifid cipher.

Bifid has a 5x5 square and folds J into I. Trifid has 27 cells: one for each letter and one for a symbol. Nothing has to share.

How do you build the cube? Write the keyword's letters, dropping repeats. Add the remaining letters from A to Z, then the symbol. Spaces and everything except ASCII letters are ignored in the key.

For `FELIX MARIE DELASTELLE`, that gives `FELIXMARDSTBCGHJKNOPQUVWYZ+`. Fill three layers, row by row:

```text
Layer 1   Layer 2   Layer 3
F E L     S T B     O P Q
I X M     C G H     U V W
A R D     J K N     Y Z +
```

The key can't move the symbol. It always takes the last cell. With no key, the cube uses the plain alphabet.

## How do the coordinates move?

Each character gets three coordinates: layer, row, column. On paper, each coordinate runs from 1 to 3. In this cube, A is `131` and `+` is `333`.

For each group, write the coordinates vertically under their characters. Read the three rows across as one line. Cut that line into threes, then look up each set in the cube. The final group can be shorter. Decoding reverses the process.

Each ciphertext letter depends on three plaintext letters. That's the fun of Trifid: the cube gives letters room to mingle.

## The 27th symbol

The default symbol is `+`. Delastelle and Wikipedia use it too. The ACA uses `#`, and other sources use `.`. Set `symbol` to match the source you're working with.

The symbol must be one character. It can't be an ASCII letter or whitespace. Digits, punctuation, `é`, and even an emoji are fine.

With `symbol: "."`, a full stop belongs to the alphabet and gets enciphered. With the default `+`, it's dropped. That 27th cell isn't just there to look square.

## What does the period do?

`period` sets the number of characters in each group. It defaults to 5 and must be a positive integer. A period longer than the text puts the whole text in one group.

What happens at `period: 1`? Nothing much. Each character's coordinates go straight back into the cube. The ciphertext equals the cleaned plaintext. That's a cube with nowhere to turn.

Wikipedia recommends a group size coprime to 3 for the most diffusion. Delastelle gives examples with groups of 5 and 7. But don't mistake diffusion for modern security. Trifid is a puzzle cipher, not a place to keep secrets.

## What gets dropped

Both directions read lowercase ASCII as uppercase. Both keep A to Z and the chosen symbol. They drop everything else, including spaces, digits, punctuation, `é`, and `ß`, unless one is the chosen symbol. Output is uppercase in one run, without spaces.

## Checked against

The opening example reproduces the [English Wikipedia example](https://en.wikipedia.org/wiki/Trifid_cipher) in both directions. The decode uses the default period of 5.

The [ACA example](https://www.cryptogram.org/downloads/aca.info/ciphers/Trifid.pdf) uses `#` and a period of 10:

```ts
const aca = { key: "EXTRAORDINARY", period: 10, symbol: "#" };

trifid.encode("trifids are fractionated ciphers", aca).text;
// "EYMXVUCRYYYYEAYVYOVVXITDPATHE"

trifid.decode("EYMXV UCRYY YYEAY VYOVV XITDP ATHE.", aca).text;
// "TRIFIDSAREFRACTIONATEDCIPHERS"
```

The ACA prints ciphertext in groups of five, with a final period. Decoding drops those spaces and the period because `#` is the symbol. Its last group has 9 letters, not 10.

The tests check both examples both ways. They also round trip a keyed cube at every period from 1 to the text length.

The CLI uses the same defaults:

```sh
ciphers encode trifid "aide-toi, le ciel t'aidera" --key "FELIX MARIE DELASTELLE"
# FMJFVOISSUFTFPUFEQQC
```

It accepts `--key`, `--period`, and `--symbol`.

## Errors and analysis

An invalid `period` or `symbol` raises `InvalidOptionError`. So does a `key` that isn't a string. Omitting the key is fine.

There are 26! possible cube orders, multiplied by the choice of period. The symbol stays fixed in the last cell.

[`guess`](/guide/analysis) doesn't know Trifid. [`recover`](/guide/analysis) doesn't take it.
